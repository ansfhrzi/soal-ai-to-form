Catatan

Ambil API key Gemini

Buka aistudio.google.com/apikey → Create API key → salin. Gratis. Beberapa proyek = beberapa key = kuota berlipat.

Keamanan

Key disimpan di Script Properties (GEMINI_KEYS) dan tidak dikirim utuh ke browser. Panel hanya menampilkan 4 digit terakhir.

Batas waktu

Rotasi berhenti setelah ±240 detik agar tidak menabrak batas 6 menit Apps Script.
