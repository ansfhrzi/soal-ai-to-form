AI: —
Mode Pratinjau (demo). Halaman ini dibuka di luar Google Apps Script, jadi tidak ada koneksi ke AI/Drive. Semua tombol memakai data contoh supaya Anda bisa melihat alur & tampilannya. Deploy ke Apps Script agar berfungsi penuh.

Cara Kerja

  1. Simpan API key di tab Pengaturan (sekali saja).
  2. Isi spesifikasi, klik Generate — AI mengembalikan JSON soal.
  3. Pratinjau & edit tiap soal, kunci jawaban, dan pembahasan.
  4. Klik Buat Google Form → form mode Kuis + spreadsheet kunci jawaban jadi otomatis.
Estimasi

10 soal ≈ 8–20 detik · ±9.000 token output.

Ambil API key Gemini

Buka aistudio.google.com/api-keys → Create API key → salin. Tiap proyek Google Cloud mendapat kuota sendiri, jadi beberapa key = beberapa proyek = kapasitas berlipat. Gratis.

Key baru keluar sebagai Auth key berawalan AQ. — itu benar dan memang bawaan Google sekarang. Standard key lama AIza… masih diterima di sini, tetapi sudah mulai ditolak Gemini API sejak September 2026, jadi sebaiknya pakai yang AQ.

Keamanan

Key disimpan di Script Properties (GEMINI_KEYS) dan tidak pernah dikirim utuh ke browser — panel status hanya menampilkan 4 digit terakhir. Jangan pernah menaruh key di file JavaScript.html.

Batas waktu

Rotasi berhenti setelah ±240 detik agar tidak menabrak batas 6 menit Apps Script. Untuk soal banyak, bagi jadi 2× generate.
